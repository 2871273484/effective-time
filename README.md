# 时光自习室

记录每次学习，自动累加每天的有效学习时间。手机和电脑看的是同一本账。

线上地址：[http://47.103.27.162:8089](http://47.103.27.162:8089)

## 能做什么

页面分成两块，右上角切换。

- **今天**：开始和结束学习，看本次计时、今日累计、8 小时进度，以及今天的时段。
- **记录**：近 7 天、月历、连续打满天数、本周和本月的饼图。点某一天（含今天）查看那天的时段，可以改时间或删除。

每天目标固定为 8 小时。统计显示到分钟，正在走的计时仍显示秒。

## 使用注意

- 没有登录。知道地址的人都能查看和修改记录。
- 使用 HTTP，传输不加密。
- 同一时间只能有一段正在学习。时段不能互相重叠，首尾相接可以。
- 跨过午夜的时段，时长按本地日期拆开计算。

## 本地运行

需要 Node.js 22 或更高版本。

```sh
npx vite build --config deploy/vite.config.mjs
node outputs/server/server.mjs
```

默认监听 `0.0.0.0:8089`。可用环境变量改端口和数据目录：

| 变量 | 默认 | 作用 |
| --- | --- | --- |
| `PORT` | `8089` | 监听端口 |
| `HOST` | `0.0.0.0` | 监听地址 |
| `DATA_DIR` | 程序目录下的 `data` | SQLite 所在目录 |

数据库文件是 `DATA_DIR/study.sqlite`。更新程序时不要覆盖这个目录。

健康检查：`GET /api/health`，正常返回 `{"ok":true}`。

更细的结构、接口和发布步骤见 [开发文档.md](开发文档.md)。
